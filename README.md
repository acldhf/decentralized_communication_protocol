基于 ipv6 ，我们做出 联络协议。请求k，获得同样请求k的ip。联络协议把大家连在一起，可以任意发ip报文。
我们采用请求响应协议。像服务器一样，不主动发消息，有事问别人，等对方回复。
基于 联络协议 与 请求响应协议，做出 话题广场。每个人可以查询别人在k处的v。
基于 话题广场 ，做出 订阅频道。每个人查询别人在k处的v，若满足一定条件，则更新自己库中k的v。条件是，1 公钥验证签名 2 seq比见过的都更大。从而这是这个公钥发出的最新消息，并向他人扩散(类似bt中的bep44协议)
基于 话题广场 ，做出 邮箱。收件人，或志愿者，查询别人在k处的v。理解为别人写给他的信(可选非对称加密)。

对于路由表,可选dht存储规则与节点质量考察,不强制.
可以仅参加联络协议.通过联络协议,可以找到你与你朋友的ip地址.可以不使用其余协议,而自由地使用ip与朋友联系,比如自行配置通信规则.(若有隐私需求,建议搭配使用非对称加密)
